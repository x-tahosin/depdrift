Architecture & Methodology

How DepDrift prevents breaking dependency updates, executes Browserbase cloud extraction, and categorizes technical risk.

Operational Risk Framework

CRITICAL
Immediate Security or Stability Hazard: Unpatched CVEs, reported remote code execution or data exposure vulnerabilities, critical memory corruption patches.
BREAKING
Architectural Incompatibility: Removed or renamed exports, major configuration schema changes, deprecated callback signatures converted to Promises without shims.
SAFE
Backwards-Compatible Improvements: Patch-level bug fixes, internal algorithmic performance improvements, non-breaking minor feature additions.
CURRENT
Up to Date: Local dependency constraint matches or is pinned to the latest upstream release tag.

Why Browserbase Headless Cloud Browser?

Modern libraries (such as Docusaurus, Next.js, VuePress, VitePress, and customized documentation portals) render changelogs client-side via JavaScript. Simple HTTP clients receive empty HTML shells (<div id="__next"></div>) with no release notes.

DepDrift solves this by connecting Playwright over Chrome DevTools Protocol (CDP) to Browserbase remote headless browser sessions. Browserbase renders the complete DOM, executes JavaScript, waits for hydration, and extracts clean, structured text for Gemma 4 analysis.

CLI & Local Execution

Run DepDrift locally in your development environment:

# Clone repository
git clone https://github.com/x-tahosin/depdrift.git
cd depdrift

# Install dependencies
pip install -r requirements.txt

# Start backend server
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
